# AI-investor
1. AI自动解析研究报告
支持上传：
- PDF
- DOCX
- TXT
- MD
也可以直接粘贴研报内容。

例如上传一份碳酸锂研究报告，系统尝试提取：
提取内容	示例
研究观点	未来一个季度碳酸锂价格偏强
供给假设	供给端增量低于预期
需求假设	下游需求保持韧性
库存假设	库存进入去化阶段
监控指标	周度产量、排产指数、产业链库存
判断阈值	产量低于8.3万吨
证伪条件	库存持续上升

支持配置 OpenAI 兼容接口；不配置 API Key 时，使用内置规则解析器演示流程。后者不是完整的大模型语义解析。
2. 建立研究假设与指标映射
每个研究假设可以设置：
- 假设名称；
- 监控指标；
- 指标单位；
- 判断阈值；
- 权重；
- 证伪条件。
3. 指标数据接入
目前支持 CSV 导入。

例如：
date,indicator,value,source
2026-11-17,产业链库存,11.6,行业数据
2026-11-17,下游排产指数,103,行业数据


导入后可以匹配研究假设，并根据最新观测值更新状态。
4. 证伪预警
系统可以识别：
- 支持
   数据符合原有假设；
- 反证
   数据不符合原有假设；
- 待验证
   缺少有效指标或阈值。
同时记录假设状态变化，供研究员复核。
5. 自动生成动态研究报告
将当前观点、假设状态、指标数据、证据和复核结论汇总成 Markdown 报告，也支持 JSON 导出。
